# RoboESP32

ชุดสื่อการสอนสำหรับหุ่นยนต์รถ **Cytron ROBO ESP32** เขียนโปรแกรมด้วย
[MicroBlocks](https://microblocks.fun) (บล็อกแบบลากวาง คล้าย Scratch แต่คอมไพล์ลงไมโครคอนโทรลเลอร์จริง)

บอร์ดจะปล่อย WiFi hotspot ของตัวเอง แล้วเสิร์ฟหน้าเว็บควบคุมออกมา
นักเรียนเปิดเบราว์เซอร์ในมือถือก็สั่งรถวิ่ง เปิดไฟ บีบแตร ขยับเซอร์โว และอ่านค่าเซนเซอร์วัดระยะได้ทันที

📖 **เว็บสอนใช้งาน:** https://alfaxphoori.github.io/RoboESP32/

---

## ในรีโปนี้มีอะไร

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `KSU_RoBoESP32.ubl` | ไฟล์ไลบรารี — บล็อกทั้งหมดที่นักเรียนเรียกใช้ในโปรเจกต์ของตัวเอง |
| `RoboCar.ubp` | ไฟล์โปรเจกต์ตัวเต็ม (เฉลย) รวมไลบรารีไว้ในตัวแล้ว เปิดแล้วแฟลชได้เลย |
| `RoboCar-Control.html` | สำเนาหน้าเว็บควบคุมแบบอ่านง่าย ไว้เปิดดู/แก้ในเบราว์เซอร์ปกติ (ไม่ใช่ไฟล์ที่บอร์ดเสิร์ฟจริง) |
| `index.html` | เว็บสอนใช้งาน 9 ด่าน ตั้งแต่ศูนย์จนคุมผ่าน WiFi ได้ |
| `library.html` | คู่มือไลบรารีฉบับเต็ม 13 บท |
| `CP210x_Windows_Drivers.zip` | ไดรเวอร์ USB สำหรับ Windows (ถ้าเสียบบอร์ดแล้วเครื่องไม่เห็นพอร์ต) |
| `images/` | ภาพหน้าจอบล็อกจริงจาก MicroBlocks ที่ใช้ในเว็บสอน |

## เริ่มใช้งานเร็ว ๆ

### สำหรับนักเรียน (เรียนไปทีละด่าน)

1. ลง **MicroBlocks** จาก [microblocks.fun](https://microblocks.fun)
2. ลง **ไดรเวอร์ CP210x** ถ้าใช้ Windows แล้วเสียบบอร์ดแล้วไม่เจอพอร์ต
3. โหลด `KSU_RoBoESP32.ubl` เก็บไว้ในเครื่อง
4. ในโปรแกรม MicroBlocks กด **+ Add Library** แล้วเลือกไฟล์ `.ubl` นั้น
5. เปิดเว็บสอนแล้วไล่ทำตั้งแต่ [ด่าน 0](https://alfaxphoori.github.io/RoboESP32/#lv0)

### สำหรับครู (อยากเห็นของจริงเลย)

1. โหลด `RoboCar.ubp` แล้วเปิดใน MicroBlocks — ไฟล์นี้มีไลบรารีอยู่ในตัวแล้ว ไม่ต้อง Add Library
2. ต่อบอร์ด กด **Start** (บล็อกธงเขียว)
3. ที่มือถือ ต่อ WiFi ชื่อ **`RoboCar`** ใส่รหัสผ่านตามที่ตั้งไว้ในบล็อก `KSU_RoBoESP32 start`
4. เปิดเบราว์เซอร์ พิมพ์ **`http://192.168.4.1`** ให้ครบทั้งบรรทัด

> รหัสผ่าน WiFi ต้องยาวอย่างน้อย 8 ตัวอักษร แก้ได้ที่ช่องในบล็อก `KSU_RoBoESP32 start`

## เส้นทางการเรียน 9 ด่าน

| ด่าน | เนื้อหา |
|---|---|
| 0 | เตรียมพร้อม — ของที่ต้องมี และโปรแกรมที่ต้องลง |
| 1 | ต่อบอร์ดและเพิ่มไลบรารี |
| 2 | ไฟ LED และ RGB |
| 3 | เสียงและดนตรี |
| 4 | มอเตอร์และการขับเคลื่อน |
| 5 | เซอร์โวและแขนกล |
| 6 | เซนเซอร์วัดระยะและเงื่อนไข |
| 7 | เปิด WiFi แล้วคุมจากเบราว์เซอร์ |
| 8 | ประกอบร่างเป็น `RoboCar.ubp` |

## หน้าเว็บควบคุม

หน้าเว็บที่บอร์ดเสิร์ฟออกมามี 3 แท็บ

- **DRIVE** — ปุ่มลูกศร ปรับความเร็ว เซอร์โว ไฟหน้า แตร ตัวเลขระยะแบบสด และคุมด้วยปุ่ม WASD บนคีย์บอร์ดได้
- **LIGHT** — เลือกสี RGB ปรับความสว่าง และเปิด/ปิดไฟ LED ทั้ง 8 ดวง
- **MORE** — สไลเดอร์เซอร์โว 4 ตัว มอเตอร์ 2 ตัว เสียง/เพลง/บี๊บ และค่าปุ่มกับระยะแบบสด

หน้าเว็บส่งคำสั่งมาเป็น path เช่น `/Forward`, `/Speed_70`, `/Rgb_2_255_120_0`
คำแรกคือชื่อคำสั่ง ตัวเลขหลัง `_` คือค่าที่ส่งมาด้วย
คำสั่งหลัก 10 คำที่สอนในห้องเรียนคือ
`Forward` `Backward` `Left` `Right` `Stop` `Light1` `Light0` `Horn` `Speed` `Servo`

## ตารางขา GPIO

| ขา | ใช้ทำอะไร |
|---|---|
| 12, 13, 14, 27 | มอเตอร์ |
| 15 | ไฟ RGB (NeoPixel) |
| 23 | ลำโพง/บัซเซอร์ |
| 4, 5, 18, 19 | หัวต่อเซอร์โว (D4 D5 D18 D19) |
| 16, 17, 21, 22, 25, 26, 32, 33 | ไฟ LED 8 ดวง |
| 33 / 32 | trig / echo ของเซนเซอร์ HC-SR04 |
| 34, 35, 36, 39 | **รับค่าได้อย่างเดียว** สั่งออกไม่ได้ |

⚠️ ขา 33 กับ 32 ใช้ร่วมกันระหว่าง LED ดวงที่ 8/7 กับเซนเซอร์วัดระยะ
ถ้าเสียบเซนเซอร์อยู่ อย่าไปสั่งเปิด/ปิด LED สองดวงนั้น

## ถ้าจะแก้ไฟล์ในรีโปนี้

โปรเจกต์นี้ไม่มีตัวคอมไพล์หรือ test ให้รัน — "การทดสอบ" คือเปิด `RoboCar.ubp`
ใน MicroBlocks แฟลชลงบอร์ด แล้วลองขับรถจริง

มีสามข้อที่พลาดกันบ่อย

1. **`RoboCar.ubp` มีสำเนาไลบรารีของตัวเอง** — แก้แค่ `KSU_RoBoESP32.ubl`
   ไฟล์ที่นักเรียนแฟลชจะไม่เปลี่ยนตาม ต้องแก้ทั้งสองไฟล์เสมอ
2. **ชื่อบล็อกที่เห็นเหมือนกัน แต่ชื่อภายในไม่เหมือน** — ในไฟล์ `.ubl` ใช้
   `KSU_RoBoESP32_forward` / `_KSU_RoBoESP32_spd` ส่วนในสำเนาที่ฝังใน `.ubp` ใช้
   `KSU_ROBOESP32_forward` / `_ksu_spd` ห้ามก๊อปโค้ดข้ามไฟล์ตรง ๆ
3. **หน้าเว็บถูกหั่นเป็นก้อนข้อความ** `_p1`..`_p8` เพราะสคริปต์เดียวใน MicroBlocks
   คอมไพล์ได้ไม่เกิน 1000 ไบต์ ถ้าจะแก้หน้าเว็บ ให้แก้ `RoboCar-Control.html` ก่อน
   แล้วค่อยหั่นใหม่ไปใส่ทั้งสองไฟล์ — ก้อนทั้งหมดต่อกันต้องเท่ากับไฟล์ HTML ที่ลบขึ้นบรรทัดใหม่ออกหมดแล้ว พอดี

ข้อจำกัดของหน้าเว็บ: ห้ามมีเครื่องหมาย `'` เด็ดขาด (GP ใช้เป็นตัวปิดสตริง ไม่มี escape),
ใช้ได้เฉพาะอักขระ ASCII (สัญลักษณ์ต้องเขียนเป็น HTML entity เช่น `&deg;` `&#9650;` หรือ JS escape เช่น `\u00b0` `\u25cf` ห้ามใส่ตัวอักษรจริง),
และห้ามใช้คอมเมนต์ `//` ใน JS เพราะขึ้นบรรทัดใหม่หายไปหมดตอนบอร์ดเสิร์ฟ

## เว็บสอนใช้งาน

`index.html` และ `library.html` ถูก deploy ขึ้น GitHub Pages อัตโนมัติทุกครั้งที่ push
เข้า `main` ผ่าน `.github/workflows/pages.yml`

> ใน Settings → Pages ต้องตั้ง Source เป็น **GitHub Actions** ไม่ใช่ Deploy from a branch
> ไม่งั้นจะมี deployment สองตัวแย่งกันจนตัวใดตัวหนึ่งถูกยกเลิก
