🗺️ โครงสร้างบทเรียน 3 คาบ

คาบละประมาณ 50 นาที จัดการเรียนรู้แบบกลุ่ม รถหุ่นยนต์ 1 คันต่อ 1 กลุ่ม

  1. คาบที่ 1: ขับรถให้ได้ก่อน (Basic Web Control)

    ต่อวงจร แฟลชโปรแกรม เชื่อมต่อ Wi-Fi แล้วลองสั่งขับรถจากมือถือ พร้อมค้นพบความลับว่า “URL ก็คือคำสั่ง” โดยพิมพ์ 192.168.4.1/Forward ลงในเบราว์เซอร์

  2. คาบที่ 2: ทำให้รถเข้าใจคำสั่ง (MicroBlocks Logic)

    เขียนลูปตรวจสอบคำสั่ง ตัวแประบล็อก if-then เพื่อเปรียบเทียบข้อความคำสั่ง พัฒนาบล็อกเองจนครบ 10 คำสั่ง แล้วเรียนรู้ทางลัดบล็อก KSU do command

  3. คาบที่ 3: เพิ่มปุ่มของตัวเอง (Custom Web UI)

    เรียนรู้โครงสร้างรหัส HTML ที่เก็บไว้ในบอร์ด ESP32 ปรับแต่งแก้ไขโค้ดเพื่อเพิ่มปุ่มคำสั่งใหม่ 3 จุด แล้วเขียนบล็อกควบคุมให้รถทำงานตามปุ่มใหม่
